# Data Model: Accountant Reports Export

No database changes. All entities below are in-memory report DTOs built from existing entities.

## ReportRequest
| Field | Notes |
|---|---|
| type | MONTHLY or YEARLY |
| fy | e.g. `2025-26` (always required; monthly derives from year+month) |
| year, month | monthly only; must fall inside the FY, not in the future |
| format | XLSX or CSV |
| requestedBy | authenticated username |

Derived: `startDate`, `endDate`, `periodLabel` (e.g. `Oct 2025 (FY 2025-26)` / `FY 2025-26`).
Validation: unknown FY format → 400; period starting after today → 400.

## ReportSummary (front page)
- Header: business name, report type, period label, start/end dates, generated at, generated by.
- Dashboard figures: totalExpense, totalIncome, netBalance (income − expense), capitalIntroduced, drawings, netCapital, loansBorrowed, loansRepaid, netLoanFlow, netCashFlow (same formulas as dashboard).
- Balance-sheet support: opening/closing capital, opening/closing loan outstanding.
- Pillar table: pillar, record count, total amount (reconciles to tab totals).
- excludedRecordCount (non-approved in period).


## LifetimeFinancials (beginning sheet 2)
- Header: business name, as-of date (report generation timestamp), generated by.
- Operational P&L:
  - globalTotalExpense
  - globalTotalIncome
  - globalNetBalance (Profit/Loss)
- Financing Pools:
  - globalCapitalIntroduced
  - globalCapitalDrawings
  - globalNetCapital
- Debt / Loan Pool:
  - globalLoansBorrowed
  - globalLoansRepaid
  - globalOutstandingLoans
- Net Cash Position:
  - globalNetCashPosition (netBalance + netCapital + outstandingLoans)
- Category Distributions:
  - globalExpensesByCategory: List of [categoryName, totalAmount]
  - globalIncomesByCategory: List of [categoryName, totalAmount]
- Loan Pool Status:
  - List of LoanSummary (loanName, lenderName, totalBorrowed, totalRepaid, outstandingBalance, status)

## PillarSection (one per pillar)
- totals: recordCount, totalAmount, totalTax (expense/income), breakdown map (category / source / type / payment mode).
- yearly only: monthly breakdown (Apr..Mar) of amount.
- timeFrame: start, end, label.
- rows: list of ReportRow.

## ReportRow (columns per pillar)
- **Expenses / Income**: date, reference id, category, sub-category, description, amount, tax %, tax amount, payment mode, status, submitted by, attachment (Yes/No), batch id.
- **Capital**: date, reference id, type (Introduced/Drawings), owner, description, amount, payment mode, status, submitted by, attachment.
- **Loans**: date, reference id, loan name, lender, type (Borrowed/Repayment), description, amount, payment mode, status, submitted by, attachment; plus per-loan summary table (opening, borrowed, repaid, closing, loan status).

Rows sorted by date ascending, then id.

## Source entities
Expense, Income, CapitalTransaction, Loan, LoanTransaction (+ Category, SubCategory, User, attachments) — read-only.
